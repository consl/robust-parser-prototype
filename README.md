# Parser Prototype (Apify-Ready Architecture)

Устойчивый шаблон парсера на Python, готовый к запуску в Docker и легкой адаптации под Apify Actors.

## Особенности
- **Надежность:** Автоматические повторные попытки (retries) с экспоненциальной задержкой через `tenacity`.
- **Чистота кода:** Type Hints, разделение ответственности (utils, parser, main), подробное логирование.
- **Изоляция:** Запуск в Docker-контейнере, вывод данных в смонтированную папку `./data`.

## Быстрый старт
1. Убедитесь, что у вас установлен Docker.
2. Создайте папку `data` в корне проекта (опционально, Docker создаст её сам).
